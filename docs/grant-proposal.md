## What This Is

An AI-driven OpenClaw skill that scans live crypto trends (CoinGecko, Reddit), generates a token concept (name, symbol, description, artwork) using GPT-4o and DALL-E 3, and launches it on Solana mainnet via Metaplex. The skill is registered as an on-chain agent via Metaplex Agent Registry and is open-source and fork-ready for any builder.
